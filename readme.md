# DROPZONE — team battle royale

Blue vs Red team deathmatch on a procedurally generated island.
Single HTML file client + Node.js WebSocket relay. Deployed free on Render.

---

## Files

- `index.html` — the game (single file, works offline too)
- `server.js` — WebSocket relay + static file server
- `package.json` — Node dependencies
- `render.yaml` — Render deployment config
- `README.md` — this file
