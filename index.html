ERANGEL STRIKE is a high-fidelity multiplayer 3D shooter prototype built entirely with Three.js. It features an Erangel-style open map — rolling hills, open fields, a small village and a river — a full tactical PUBG-mobile-like UI, team-deathmatch combat across three weapon classes, AI bots, and pluggable networking (offline / LAN / online).

All 3D models and textures are generated procedurally at runtime, so the whole game ships in one self-contained HTML file with zero external asset downloads — only Three.js is fetched from a CDN. See README.md for the royalty-free asset source list and the full build roadmap.
